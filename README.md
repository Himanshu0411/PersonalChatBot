# Personal Chat Assistant (Python Chatbot)

## 📌 Project Description

This project is a simple **Python-based chatbot** that interacts with the user through the command line.
The chatbot greets the user based on the current time of the day and answers some predefined questions using a dictionary of responses.

The chatbot continues the conversation until the user types **"bye"**.

---

## 🚀 Features

* Greets the user according to the time (Morning / Afternoon / Evening / Night)
* Responds to basic queries
* Uses a dictionary to store chatbot responses
* Continuous chat using a loop
* Exit option using the keyword **"bye"**

## ▶️ How to Run the Project

1. Install Python on your system.
2. Download or clone the project.
3. Open the project folder in terminal or command prompt.
4. Run the following command:

```
python chatbot.py
```
